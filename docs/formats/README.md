# Data formats

Each versioned format gets a spec here as it is built:

| Format | Milestone | Spec |
|---|---|---|
| Coordinator ↔ twin protocol (schema_version 1) | M0 | [`../design/protocol.md`](../design/protocol.md) |
| Trace (`results/<run_id>/traces/*.json`) | M1 | not written |
| Session (`sessions/*.jsonl`) | M2 | not written |
| Findings (`results/<run_id>/findings.json`) | M3 | not written |
| Run metadata (`results/<run_id>/run.json`) | M3 | not written |
